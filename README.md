# Maturski rad - Izrada Web stranice
**Učenik:** Ishak Skomorac
**Mentor:** Edin Heco

Ovaj projekat predstavlja praktičnu implementaciju maturskog rada na temu "Izrada Web stranice". 
Cilj je demonstrirati osnovne tehnologije modernog weba:
- **HTML5** za strukturu sadržaja
- **CSS3** za dizajn i responzivnost
- **JavaScript** za interaktivnost i dinamiku

Stranica je zamišljena kao lični portfolio koji prati teoretske osnove iznesene u radu.
